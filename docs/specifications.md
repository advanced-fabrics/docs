# Specifications

Specifications define the stable behavior; implementation repositories show one way to realize it.

## Normative material

- [Specifications](https://github.com/advanced-fabrics/spec): normative text, compatibility policy, and AFEPs.
- [API contracts](https://github.com/advanced-fabrics/api): OpenAPI, JSON Schema, and protobuf source.
- [AFEP process](https://github.com/advanced-fabrics/spec/blob/main/afeps/0000-process.md): how standards changes are proposed and reviewed.

## Conformance

The [conformance repository](https://github.com/advanced-fabrics/conformance) contains public assertions. Claims should identify the exact tested artifact digest. The 1.0 roadmap requires fresh-install, upgrade, provider-replacement, and multi-cluster suites.

## Release status

Version 1.0 has not been declared generally available. Track the [release gates](https://github.com/advanced-fabrics/community/blob/main/ROADMAP.md) and public release decisions before treating any contract or implementation as final.
