Quick Start

The 1.0 release is gated and not yet declared generally available. Until signed release artifacts are published, evaluate from source and do not use an unverified latest tag.

  1. Inspect the API contracts in advanced-fabrics/api.
  2. Choose the reference runtime or compatible providers.
  3. Run the public conformance suite against the exact artifact digest.

Safety model

AdvFab defaults to observation. Apply operations require provider capability, explicit policy, RBAC and authenticated identity. Missing observations remain unavailable and are never replaced with invented values.
