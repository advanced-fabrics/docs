Specifications

Specifications define the stable behavior; implementation repositories show one way to realize it.

Normative material

  • Specifications: normative text, compatibility policy and AFEPs.
  • API contracts: OpenAPI, JSON Schema and protobuf source.
  • AFEP process: how standards changes are proposed and reviewed.

Conformance

The conformance repository contains public assertions. Claims should identify the exact tested artifact digest. The 1.0 roadmap requires fresh-install, upgrade, provider-replacement and multi-cluster suites.

Release status

Version 1.0 has not been declared generally available. Track the release gates and public release decisions before treating any contract or implementation as final.
